# Aura Couture

Native Android application for a fashion boutique, built with **Java and XML layouts** in Android Studio.

## Project scope
- Employee workflows: products, inventory, customers, orders, and business insights.
- Customer workflows: browse the catalogue, request orders, view order history, and use AI styling.
- One Android application with role-aware navigation.
- AI features are optional; core catalogue and order workflows must work without AI.
- No subscriptions, premium tiers, payment gateway, or monetisation in the initial coursework scope.

## Technology direction
- Android Studio, Java, XML layouts, Activities and Intents.
- Supabase is the proposed backend substitution for Firebase. Confirm with the lecturer that this is acceptable before relying on it for assessment.
- Never put Supabase service-role keys or AI-provider secrets in the Android APK.
